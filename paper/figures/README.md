# Figures

This directory holds the rendered figures cited from `manuscript.tex`.
The manuscript wraps every `\includegraphics` call in
`\IfFileExists{...}` so a `make paper` build succeeds even when the
PDF/PNG hasn't been generated yet — missing figures fall back to
labelled placeholder boxes.

|-----------------------|------------------------------------------------------------------------------------|----------------|
| `architecture.pdf`    | Frontend export: open the **Audit** page, click *Export architecture diagram*. Or run `make architecture` (TODO) which renders `docs/diagrams/architecture.dot` via Graphviz. | `\ref{fig:arch}` |
| `dag.pdf`             | Generated by `python -m src.guardian.causal.dag_schema --render figures/dag.pdf` (one-shot helper that calls NetworkX → Graphviz on the standard DAG). | `\ref{fig:dag}` |

| `latency_budget.pdf`  | Stage-wise box-and-whisker plot. Generated from `data/eval-results/latency.json` by `scripts/plot_latency.py` (TODO). | Section~5.4   |

## Placeholder behaviour

When a figure is missing, the manuscript renders a labelled
`\fbox{...}` block describing the intended figure. This keeps the
build green during iterative writing. To verify the placeholder
rendering, build the paper without dropping any PDFs into this
directory; to verify the real-figure path, drop the corresponding
PDFs in here and rebuild.

## Why no committed binaries?

Until a figure is final we'd rather render it on demand from the
underlying data + script than commit a PDF that will go stale. That
keeps the repo lean and the figures reproducible.
